Timeframe

Start must be before End (no midnight crossing)

How to read a cell

 | ➕ Remaining ➖ |  ← time remaining today
        (Used)         ← time already used
      TimeFrame 🗓     ← allowed hours
  • ➕ / ➖ — add/remove 10min allowed (applies to that weekday, every week)
  • 🗓 — change the allowed time-window
  • ⏯️ — pause-block device for 20min
  • 🔒/🔓 — toggle enforcement (🔒 shown = enforcing; tap to set free-mode)
